# Luma3DS (BBP Online Fork)

[English](README.md) | [日本語](README_ja.md)

「大合奏！バンドブラザーズP」の「近くの人と合奏」を、インターネット越しに遊べるLuma3DSのフォークです。本体のローカル無線通信（UDS）をリレーサーバで中継します。

## 特徴と仕組み

- **ゲーム内の操作**<br>
  Relayを設定した後は、ゲーム内で「近くの人と合奏」を選んで部屋を作るか、募集されている部屋に参加します。
- **Rosalinaメニューから設定**<br>
  BBPを終了した状態で<kbd>L</kbd>+<kbd>Down</kbd>+<kbd>Select</kbd>を押し、「BBP Online」を開きます。通常は初期設定のままRelayをONにしてからゲームを起動してください。仲間内だけで遊ぶ場合は、先に共有したPINを設定します。詳しくは[遊び方](#遊び方)を参照してください。<br>
  BBP起動中はRelayの有効化や設定変更はできません（Status画面の確認は可能です）。
- **Status画面（サーバ状況の確認）**<br>
  メニューの「Status」から、リレーサーバとの通信遅延（Ping/RTT）や接続人数（Online）、各チャンネルで募集中の部屋数（Recruiting）、演奏中の部屋数（In game）を確認できます（<kbd>X</kbd>で再取得）。BBP起動中も確認できます。
- **暗号化通信**<br>
  本体とリレーサーバの間の通信は、Noise NN（ChaCha20-Poly1305 / BLAKE2b）で暗号化します。通信内容はリレーサーバで復号されます。接続先が正しいサーバかを確かめる認証は行いません。
- **リレーサーバについて**<br>
  初期接続先は`bbprelay.f5.si:24873`です。別のリレーサーバを使う場合は、メニューの「Custom 1〜3」にアドレスを設定してください。

## 前提条件

参加者全員に次のものが必要です。

- **製品版「大合奏！バンドブラザーズP」**（パッケージ版、またはダウンロード版）
- **更新データ Ver. 2.1**
- 本forkを導入した3DS本体

ダウンロードプレイには対応していません。

## 遊び方

### だれかと合奏する（通常）

初期設定のまま、ゲーム内の「近くの人と合奏」から部屋を作るか、募集されている部屋に参加します（PINは`0000`）。

チャンネルは通常、変更する必要はありません。1つのチャンネルで同時に募集できるのは4部屋までです。募集枠が埋まっていて部屋を作れない場合は、BBPを終了してから別のチャンネル（1〜5）へ切り替えてください。各チャンネルの空き状況はStatus画面で確認できます。

### 仲間内だけで合奏する（PIN）

特定の仲間だけで集まって遊びたい場合は、事前に4桁のPIN（`0001`〜`9999`）を決めて共有し、全員が同じPINを設定します。同じPINの人が作った部屋だけがゲーム内に表示されます（チャンネル設定は無視されます）。

同じPINを設定すれば誰でも参加できるため、PINは一緒に遊ぶ仲間だけに教えてください。

### 起動時の設定

本体を起動すると、RelayはOFF、チャンネルは`1`、PINは`0000`に戻ります。遊ぶときは、BBPを起動する前に設定してください。

## 導入について

[Releases](https://github.com/suke0930/Luma3DS-BBP-Online/releases)から`boot.firm`をダウンロードしてください。現在の`boot.firm`をバックアップしてから、ダウンロードしたファイルをSDカードのルートへコピーしてください。
