# Luma3DS (BBP Online Fork)

[English](README.md) | [日本語](README_ja.md)

3DSのオンラインサービス終了後も、「大合奏！バンドブラザーズP」でインターネット越しの合奏を可能にするための Luma3DS カスタムフォークです。

本来は同じ場所に集まって遊ぶ「近くの人と合奏」（ローカル無線通信 / UDS）のパケットを、インターネット上のリレーサーバ経由で中継することで、離れた場所にいるプレイヤー同士でのオンライン合奏を実現します。

## 特徴と仕組み

- **ゲーム側は「近くの人と合奏」を選ぶだけ**  
  ゲーム内のローカル通信を本体（Luma3DS）側で自動的にネットへ中継するため、ゲーム内では普段通り「近くの人と合奏」を選ぶだけで遠くのプレイヤーと合奏できます。
- **Rosalinaメニューから設定**  
  BBPを終了した状態で<kbd>L</kbd>+<kbd>Down</kbd>+<kbd>Select</kbd>を押し、「BBP Online」を開きます。参加者全員で接続先と公開チャンネル（1〜5）または4桁PINを揃え、RelayをONにしてからゲームを起動してください。Relayは本体起動時にOFFへ戻ります。BBP起動中はRelayの有効化や設定変更はできませんが、接続状態や遅延（Ping/RTT）は確認できます。
- **暗号化通信**  
  合奏パケットは本体とリレーサーバの間でNoise NN（ChaCha20-Poly1305 / BLAKE2b）を使って暗号化されます。接続先サーバの認証や、プレイヤー間のエンドツーエンド暗号化は行いません。リレーサーバは通信内容を復号できます。4桁PINは部屋を分けるための番号で、本人認証ではありません。
- **リレーサーバについて**  
  初期設定でオンラインサーバ（`bbprelay.f5.si:24873`）が登録されています。メニューの「Custom 1〜3」から、任意のリレーサーバのアドレスへ切り替えて遊ぶことも可能です。

## 前提条件

本機能でオンライン合奏を楽しむには、参加者全員が以下をお手元に用意していただく必要があります。

- **製品版「大合奏！バンドブラザーズP」**（パッケージ版、またはダウンロード版）
- **更新データ Ver. 2.1**
- 本カスタムLuma3DSが導入された3DS本体

※本機能は製品版同士での合奏を前提としています。ダウンロードプレイでの動作には対応していません。

## チャンネルとPIN

合奏する全員で同じリレーサーバを選び、以下の設定を揃えてください。

| PIN | 参加者が揃える設定 |
|---|---|
| `0000`（公開） | 同じチャンネル（1〜5） |
| `0001`〜`9999`（PIN指定） | 同じ4桁PIN。チャンネルは無視されます |

チャンネルとPINは保存されません。本体を再起動すると、チャンネルは`1`、PINは`0000`へ戻ります。設定はBBPを起動する前に行ってください。
