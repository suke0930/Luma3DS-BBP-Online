## データの保存と公開

通信は合奏を中継するためリレーサーバー上で復号されます。データの扱いは以下のとおりです。

- **常時保存する管理情報**：3DS端末固有ID、接続状況や遅延、IPアドレス等の接続元情報を、安全確保やパフォーマンス監視・統計、障害対応、法令に基づく要請への対応のため、期間の定めなく保存します。
- **7日間保持する全通信データ**：公開・PIN利用時を問わず、サーバーを経由する全通信データを、不正対策と調査のため暗号化して7日間保持します。不正の疑いがある場合は調査に必要な期間延長して保持し、不要になり次第削除します。
- **保存しないデータ**：譜面名・作曲者名を除く譜面の中身、アバター等のユーザーデータ、演奏結果のスコア、端末固有ID以外の3DS固有情報は保存しません（上記の7日間保持する通信データには含まれます。また、本人の許可や申告がある場合は保存することがあります）。
- **公開セッションで公開する情報**：プレイヤーに関する情報（プレイヤー名）と、セッション（部屋）ごとの情報（ホスト・ゲストの区別、譜面名・作曲者名、演奏曲数/プレイ時間）をWebサイト等で公開する可能性があります。また、保存しないと明記したものを除き、実験・開発のため一時保存することがあります（非公開）。
- **PIN利用時の扱い**：プレイヤー名や譜面名などの参加情報は、通常の記録として保存・公開せず、実験・開発用の保存も行いません。ただし、管理情報の記録と、通信データの7日間保持は対象です。
- **全体の集計**：リレー接続人数と部屋総数（PIN利用時を含む）は、個人を特定できない形で集計・公開します。

公開情報・集計を除き、法令に基づく場合以外に保存データを第三者へ提供しません。サービス終了後も保存済みの情報はプライバシーポリシーに従って扱い、方針を変える場合は事前に告知します（告知前の取得分には遡及しません）。
