# Luma3DS (BBP Online Fork)

[English](README.md) | [日本語](README_ja.md)

「大合奏！バンドブラザーズP」の「近くの人と合奏」を、インターネット越しに遊べるLuma3DSのフォークです。本体のローカル無線通信（UDS）をリレーサーバーで中継します。

## 公式サーバーの利用規約とデータの取扱い

本リポジトリのソフトウェア自体はオープンソース（GPLv3）であり、独自にリレーサーバーを立てて利用する場合は以下の規約の対象外です。

一方、初期設定の**Project Phonographの公式リレーサーバー（`bbprelay.f5.si:24873`）**、関連Webサイト（公開予定）、運営コミュニティ（`suke0930` 運営）を利用する場合は、以下の規約とポリシーが適用され、**接続・利用を開始した時点で同意したものとみなします**。

- **公開セッションの情報公開**：公開合奏（PIN `0000`）では、プレイヤー名や部屋の譜面名・演奏曲数・プレイ時間などをWebサイト等で公開する可能性があります（スコアや譜面データ本体は保存しません）。
- **不正対策のための通信保持**：公開・PIN利用時を問わず、端末固有IDやIPアドレス等の管理情報を保存し、経由する全通信データを不正対策のため暗号化して7日間保持します。
- **禁止事項**：荒らしや過負荷行為、および通信パケットのキャプチャ等による譜面データや他プレイヤー情報の抽出・収集は、公開・PIN利用時を問わず禁止です。チート・スクリプト類は公開セッションでは禁止、PIN指定時のみ他セッションやサーバーに影響しない範囲で例外として認めます。

利用前に必ず **[全体の要約](docs/terms/README.md)** を確認してください。各条件の詳細は以下に記載しています。

- [利用規約](docs/terms/user-terms.md)（同意、禁止行為、配信・録画、BAN、規約変更）
- [運営方針・サービス提供条件](docs/terms/service-policy.md)（無料提供、利用停止・BAN、中断・終了、無保証）
- [プライバシーポリシー](docs/terms/privacy-policy.md)（保存する情報・しない情報、7日間保持、公開範囲、削除相談）

## 前提条件

参加者全員に次のものが必要です。

- **カスタムファームウェア（boot9strap / Luma3DS）導入済みの3DS本体**
- **3DS本体がインターネット（Wi-Fi）に接続できる環境**
- **製品版「大合奏！バンドブラザーズP」**（パッケージ版、またはダウンロード版）
- **更新データ Ver. 2.1**（ゲーム起動時のタイトル画面右下等で「Ver. 2.1」と表示されていることを確認してください）

※1台のソフトから配信して遊ぶ「ダウンロードプレイ」には対応していません。

## Rosalinaメニューでの設定

ゲームを起動する前に、Rosalinaメニューから通信設定を行います。
※ゲーム起動中は設定変更ができません。設定を変えたい場合は一度ゲームを終了してください。

### メニューの開き方
1. ゲーム（BBP）を終了した状態で、<kbd>L</kbd>+<kbd>Down</kbd>+<kbd>Select</kbd> を押してRosalinaメニューを開きます。
2. メニューから「**BBP Online**」を選択します。

### 設定項目の見方と操作
- **Relay: OFF / ON**
  中継機能のON / OFFを<kbd>A</kbd>で切り替えます。遊ぶときは「ON」にしてからゲームを起動してください。
- **Room passphrase**（4桁のPIN）
  合奏の参加範囲を分ける番号です。<kbd>A</kbd>で入力画面を開き、<kbd>Left</kbd>/<kbd>Right</kbd>で桁移動、<kbd>Up</kbd>/<kbd>Down</kbd>で数値変更、<kbd>A</kbd>で保存します（<kbd>B</kbd>でキャンセル）。
  - `0000`（初期値）：だれかと合奏（通常）。全体に公開され、下記のChannelが有効になります。
  - `0001`〜`9999`：仲間内だけで合奏（PIN指定）。同じPINを設定した人同士にだけ部屋が表示されます（Channelは無視されます）。
- **Channel**（1〜5）
  だれかと合奏（PIN `0000`）のときに、公開の募集枠（1チャンネルにつき最大4部屋）を切り替えます。<kbd>A</kbd>でリストを開き、<kbd>Up</kbd>/<kbd>Down</kbd>で選んで<kbd>A</kbd>で保存します。仲間内合奏（PIN指定時）では使われません。
- **Status**
  リレーサーバーとの通信遅延（Ping/RTT）や接続人数（Online）、各チャンネルの募集中部屋数、演奏中の部屋数を確認できます（<kbd>X</kbd>で再取得、<kbd>B</kbd>で戻る）。BBP起動中も確認可能です。
- **Relay server...**
  接続先のリレーサーバーを選択します。初期設定はOfficial（`bbprelay.f5.si:24873`）です（Officialへ接続する場合は[公式サーバーの利用規約とデータの取扱い](#公式サーバーの利用規約とデータの取扱い)が適用されます）。別のリレーサーバーを使う場合は、Custom 1〜3を選び、<kbd>X</kbd>でアドレス（IPv4:ポート）を編集して<kbd>A</kbd>で選択します。

### 設定の保存について
- **Relay、Channel、Room passphrase**<br>
  本体の電源を切る・再起動すると、安全のため初期値（Relay: OFF、Channel: 1、PIN: 0000）に戻ります。遊ぶときは、ゲームを起動する前にRosalinaでRelayをONにしてください。
- **Relay server...（カスタムサーバー設定）**<br>
  入力したアドレスや選択したサーバーはSDカードに自動保存されるため、本体を再起動しても保持されます。

## 遊び方

### だれかと合奏する手順（通常）
1. 初期状態（`Channel: 1`、`Room passphrase: 0000`）のままでOKです。
2. `Relay` を選び、<kbd>A</kbd> を押して「**Relay: ON**」にします。
3. <kbd>B</kbd> でRosalinaを閉じ、BBPを起動します。
4. ゲーム内で「近くの人と合奏」を選び、**1人が部屋を作り（募集）、他の人は募集されている部屋に参加**します。
※もしチャンネル1の募集枠（4部屋）が埋まっていて部屋を作れない場合は、BBPを終了してから `Channel` で空いている別のチャンネル（2〜5）へ切り替えてください（空き状況はStatus画面で確認できます）。

### 仲間内だけで合奏する手順（PIN）
1. 一緒に遊ぶ仲間と、事前に4桁のPIN（`0001`〜`9999`）を決めておきます。
2. `Room passphrase` を選び、決めた4桁のPINを入力して <kbd>A</kbd> で保存します。
3. `Relay` を選び、<kbd>A</kbd> を押して「**Relay: ON**」にします。
4. <kbd>B</kbd> でRosalinaを閉じ、BBPを起動します。
5. ゲーム内で「近くの人と合奏」を選び、**1人が部屋を作り、他の人はその部屋に参加**します。同じPINを設定した人が作った部屋だけが表示されます。
※同じPINを設定すれば誰でも参加できるため、PINは一緒に遊ぶ仲間だけに教えてください。

## 技術仕様とセキュリティ

本体とリレーサーバー間の通信は Noise NN（`ChaCha20-Poly1305` / `BLAKE2b`）で暗号化されますが、中継のためリレーサーバー上で復号されます。また、接続先が意図したサーバーであるかを確認するサーバー認証は行いません。
