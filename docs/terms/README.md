## データの保存と公開

- 端末固有ID、接続状況・遅延、IPアドレス等を、安全確保、障害対応、法令に基づく要請への対応のため保存します。
- 公開・PIN利用時の双方で、経由するすべての通信データを、不正対策・原因究明・調査のため暗号化して7日間保持します。不正の疑いがあるデータは、調査等に必要な場合に限り7日間を超え、必要に応じて期限を定めず保持する場合があります。延長対象でないデータは7日間の経過後に削除し、延長したデータも必要がなくなった時点で削除します。
- 通信はリレーサーバーで復号して中継します。譜面データ、アバター等のユーザーデータ、端末固有ID以外の3DS固有情報は、通常の記録として保存しません。ただし、譜面名・作曲者名は公開セッションで記録・公開し、それ以外の情報も前項の通信データには含まれる場合があります。ユーザーデータは、本人への確認と許可、または本人からの申告によって収集・保存する場合もあります。
- 公開合奏セッションでは、プレイヤー名、ホスト・ゲストの区別、譜面名・作曲者名、継続時間・演奏曲数を公開します。
- PIN利用時は、これらの参加情報を通常の記録として保存・公開しません。ただし、端末固有ID・接続状況・接続元情報の記録と、不正対策のための全通信データの保持は対象となります。
- リレー接続人数と部屋総数は、個人を特定できない形で集計・公開します。PIN利用時の分も集計に含みます。
- スコアと選んだパート・楽器情報は現在の方針では公開しません。保存しないと明記したものを除く公開セッション内の情報を、実験・開発のため一時保存する場合がありますが、公開はしません。PIN利用時はこの実験・開発のための保存を行いません。
- 定めた公開情報・集計の公開を除き、保存した情報を法令に基づく場合以外に第三者へ提供しません。通信データは不正対策等の定めた目的以外に参照・利用しません。

中断・終了後も、保存済みの情報はプライバシーポリシーに従って取り扱います。データ取扱いの方針変更は事前に告知し、告知前に取得した情報には変更後の方針を適用しません。
